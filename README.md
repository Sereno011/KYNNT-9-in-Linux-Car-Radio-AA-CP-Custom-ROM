# KYNNT-9-in-Linux-Car-Radio-AA-CP-Custom-ROM
This is a custom ROM for a Linux based 9" car radio. With the help of AI all the wallpapers were changed and several OEM boot logos swapped. Logos customized for the NA market, replacing European specific ones. This specific ROM modified from a QX128A-104HIP BIOS chip (EN25QH128 compatible). KYNNT was the Amazon seller of this model.
